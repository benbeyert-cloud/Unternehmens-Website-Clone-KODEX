# Unternehmenswebsite Clone

Dieses Projekt ist ein Nachbau einer modernen Unternehmenswebsite, erstellt mit **HTML**, **CSS** und **JavaScript**.

## Features

* Responsives Design
* Moderne Benutzeroberfläche
* Interaktive Elemente mit JavaScript
* Saubere Struktur und einfache Navigation

## Verwendete Technologien

* HTML5
* CSS3
* JavaScript

## Installation

1. Repository klonen:

```bash
git clone https://github.com/dein-benutzername/dein-repository.git
```

2. Projektordner öffnen

3. `index.html` im Browser starten

## Ziel des Projekts

Dieses Projekt wurde erstellt, um Frontend-Entwicklung und modernes Webdesign zu üben und zu verbessern.
